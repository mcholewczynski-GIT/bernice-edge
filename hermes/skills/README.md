# Hermes skills (Bernice)

Install a skill on the Spark by linking it into Hermes's skills folder:

```
ln -s ~/bernice-edge/hermes/skills/bernice-edge ~/.hermes/skills/bernice-edge
hermes skills list
```

| Skill | Purpose |
|---|---|
| `bernice-edge` | Delegate image jobs to the Bernice Edge node (Crestron Collab Compute) |
